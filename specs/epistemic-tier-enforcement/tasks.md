retired by T2/T3 above. The remaining three are now also retired, leaving the
allowlist empty:

- **Edge 4 — `pairing.py` → `.similarity` (lazy scorer import).** Resolved by

  place; the census unit tests pass unchanged before and after. Callers (the
  exploratory candidate assets, the opportunity script, the opportunity test)
  import S2/S3 from the new module.

  `text_inference`.** The strategy is a live consumer (the exploratory
  `fiscal_assets` asset via `enrich_sbir_awards_with_fiscal_naics`), not dead. The
  `strategies/__init__` re-export was dead and is removed. `default_strategies`
  drops the static `text_inference` import and gains an `extra_strategies`

  parameter. The deterministic pipelines default is unchanged minus the
  exploratory step; consumer behavior is preserved and its tests pass.
