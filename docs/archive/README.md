# Archive

Superseded documents kept for provenance. **Nothing here describes current
behaviour.** Read it to understand why something was done, never to learn how
the system works now.

Repository hygiene checks treat this directory differently from live
documentation: stale commands and references to removed code are expected here
and are not reported. That exemption is the reason to move a document in rather
than delete it — and the reason not to link to one from live documentation as
though it were current.

| `design/` | Implemented feature designs, retained as the design record |
| `development/` | Cleanup and source-layout migration snapshots |
| `enrichment/` | Enricher consolidation migration |
| `performance/` | Superseded performance playbook |
| `research/` | Superseded research results and plan-alignment snapshots |
