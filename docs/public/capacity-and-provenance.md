# Capacity and provenance

This page states in what capacity this work is done, what its names mean, and
what inputs it accepts. It applies to every path in the repository.

## Capacity

This repository is a personal project of its maintainer. It is not the work
product of a government agency. No agency sponsors, funds, directs, reviews, or
approves it. Nothing here states the position of an agency.

## Names and personas

An agency name in a path or title identifies the public document or dataset
that a study examines. For example, `sba-annual-report` refers to the published
SBA Annual Report as a source. It does not identify a sponsor, a customer, or a
requester.

Specs use a user-story format, such as "As an SBIR program manager, I want…".
These personas are hypothetical readers that the
[spec template](../../specs/REQUIREMENTS_TEMPLATE.md) asks each spec to name.
They are not requirements from an agency, an office, or a person.

"Approved evidence" is a label from this repository's own review process, as
the [evidence-status guide](evidence-status.md) defines it. It does not mean
that an agency approved, adopted, or endorsed a result.

## Inputs

The repository accepts public sources only. Each study input must have a public
download location and a hash in its source manifest. Any member of the public
must be able to retrieve the same bytes.

Do not add data that comes from employment, credentials, agreements, or other
non-public access. This rule also covers data that is derived from such access.

## Outputs that name firms

Some outputs name firms. These outputs come from public records and from the
declared rules of one analysis. They are not a rating, a ranking, an
endorsement, or a finding about eligibility or compliance.

These outputs are not made to select firms for awards, visits, meetings, or
other official attention. A person who uses them for that purpose does so on
that person's own authority.
